# SPI-Based Automated Cotton Cutting System

## Overview

A Verilog HDL project that simulates an automated cotton-cutting factory using SPI communication.

The system consists of one SPI Master controlling three independent SPI Slave modules. Each slave represents a cotton-cutting machine that processes a specific number of cotton units before requesting permission to rest.

The master coordinates all three machines to ensure that at least one machine remains active at all times.

## System Architecture

**One Master – Three Slaves**

| Module | Cotton per Batch |
|---|---:|
| Slave 1 | 3 units |
| Slave 2 | 4 units |
| Slave 3 | 5 units |

### SPI Communication

The system uses four standard SPI signals:

- **MOSI:** Master sends commands to slaves.
- **MISO:** Slaves send status information to the master.
- **SCLK:** Clock generated by the master.
- **CS1, CS2, CS3:** Individual slave selection signals.

Communication uses SPI Mode 0.

## Working Principle

1. All three slave machines begin cutting cotton.
2. Each slave processes its predefined batch quantity.
3. After completing a batch, the slave requests permission to rest.
4. The master polls all slaves and checks their operating status.
5. The master grants rest only if at least one other machine remains active.
6. Each slave rests for a fixed duration of 20 clock cycles before resuming operation.
